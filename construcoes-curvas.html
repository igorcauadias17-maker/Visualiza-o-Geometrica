Curvas clássicas e curvas espaciais

As construções abaixo apresentam diferentes comportamentos: curvas helicoidais, curvas de interseção, curvas fechadas e curvas planas vistas como curvas em R³.

Hélice circular

A projeção da hélice gira em torno do eixo vertical enquanto sua altura cresce uniformemente. Trata-se de um exemplo importante de curva espacial com curvatura e torção constantes.

α(t) = (a cos t, a sin t, b t),   0 ≤ t ≤ 6π

Arraste a figura para girar a perspectiva.

Curva de Viviani

É a interseção de uma esfera com um cilindro circular tangente à esfera. Sua forma evidencia como uma curva espacial pode surgir da interseção de duas superfícies.

γ(t) = (a(1 + cos t), a sin t, 2a sin(t/2)),   0 ≤ t ≤ 2π

Arraste a figura para girar a perspectiva.

Nó trevo

O nó trevo é uma curva fechada que se entrelaça no espaço. É um exemplo clássico para visualizar curvas parametrizadas que não são planas.

τ(t) = (sin t + 2 sin 2t, cos t − 2 cos 2t, −sin 3t),   0 ≤ t ≤ 2π

Arraste a figura para girar a perspectiva.

Ciclóide

A ciclóide plana é traçada por um ponto de uma circunferência que rola sem deslizar sobre uma reta. Aqui ela é representada no espaço, contida no plano xz.

c(t) = (t − sen t, 0, 1 − cos t),   0 ≤ t ≤ 4π

Arraste a figura para girar a perspectiva.

Catenária

A catenária é a forma assumida por um fio perfeitamente flexível, homogêneo e suspenso apenas pelas extremidades, sob a ação da gravidade. É uma curva plana, apresentada aqui no plano xz.

h(t) = (t, 0, cosh t),   −1,5 ≤ t ≤ 1,5

Arraste a figura para girar a perspectiva.

Curva de Lissajous espacial

Esta curva é construída combinando movimentos oscilatórios em três direções. A escolha de frequências diferentes produz uma trajetória fechada e visualmente rica.

ℓ(t) = (sen 3t, sen 4t, sen 5t),   0 ≤ t ≤ 2π
